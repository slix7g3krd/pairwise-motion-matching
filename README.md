# pairwise-motion-matching

角色从走到跑切换时脚底打滑、急停滑步、转身动作穿模：动作库按帧率采样；轨迹特征只有速度；代价函数权重固定；候选搜索用最近邻但不做连续性；混合窗口按帧数；根运动没剥离；转身用目标朝向硬切；地面高度没参与匹配；动作库不同骨架没重定向；帧率波动导致选动作跳。game/motion_matching.py 是核心，tests/test_motion_matching.py 15个红。要修的是：时间归一采样；轨迹+姿态特征；自适应权重；连续性惩罚；时间窗口；根运动剥离；转身过渡；地面高度；骨架重定向；帧率无关。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
